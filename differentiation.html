Differentiation

Differentiation is a fundamental concept in calculus that deals with the rate at which a function changes. It is the process of finding the derivative of a function, which represents the slope of the function at any given point.

Basic Differentiation Rules

There are several basic rules for differentiation that can be applied to various types of functions. Some of the most commonly used rules include:

  • Power Rule
  • Constant Rule
  • Sum Rule
  • Difference Rule
  • Chain Rule

Basics of Differentiation

Say we have a function named f(x)

We can find the derivative of f(x) using the following notation:

f'(x) or df/dx

Power Rule

If f(x) = xn, then f'(x) = n*x(n-1)

Constant Rule

If f(x) = c then f'(x) = 0 (Differentiation of constant always results in zero)

Sum Rule

If f(x) = g(x) + h(x) then f'(x) = g'(x) + h'(x)

Now this means that the derivative of function containing multiple terms can be found by differentiating each term separately.

Difference Rule

If f(x) = g(x) - h(x) then f'(x) = g'(x) - h'(x)

This concept is similar to the sum rule, but instead of adding the derivatives of each term, we subtract them.

Chain Rule (Whole power function differentiation)

If f(x) = [g(x)]n, then f'(x) = n*[g(x)](n-1) * g'(x)

In other words, the derivative of a composite function is the derivative of the outer function times the derivative of the inner function.

Having a strong grasp of these rules is essential for success in calculus.

Further Differentiation (AS revision)

In this section, we will explore the main course of differentiation, which involves applying the basic rules to more complex functions. We will also discuss higher-order derivatives and their applications.

Higher-Order Derivatives

Higher-order derivatives are the derivatives of derivatives. The second derivative, denoted as f''(x) or d2f/dx2, represents the rate of change of the first derivative. Similarly, the third derivative, denoted as f'''(x) or d3f/dx3, represents the rate of change of the second derivative, and so on.

Differentiation of Logarithmic Functions

In the syllabus, the logarithm will contain only the natural logarithm (ln) for differentiation.

Logarithmic functions are the functions that contain the variable in the argument of the logarithm. The derivative of a logarithmic function can be found using the formula:

The following general formula is used to differentiate logarithmic functions:

If f(x) = ln(g(x)), then f'(x) = g'(x) / (g(x))

Where f(x) is the given function and g(x) is the function within the logarithm.

Differentiation of Exponential Functions

Exponential functions are the functions that contain the variable in the exponent. The derivative of an exponential function can be found using the formula:

If f(x) = eg(x) then f'(x) = eg(x) * g'(x)

where f(x) is the given function, g(x) is the function in the exponent, and e is the base of the natural logarithm.

Differentiation of Trigonometric Functions

Trigonometric functions are the functions that involve trigonometric ratios. The derivatives of the basic trigonometric functions are:

  • If f(x) = sin(g(x)), then f'(x) = cos(g(x)) * g'(x)
  • If f(x) = cos(g(x)), then f'(x) = -sin(g(x)) * g'(x)
  • If f(x) = tan(g(x)), then f'(x) = sec2(g(x)) * g'(x)
  • If f(x) = cot(g(x)), then f'(x) = -cosec2(g(x)) * g'(x)
  • If f(x) = sec(g(x)), then f'(x) = sec(g(x)) * tan(g(x)) * g'(x)
  • If f(x) = cosec(g(x)), then f'(x) = -cosec(g(x)) * cot(g(x)) * g'(x)
  • If f(x) = tan-1(g(x)), then f'(x) = g'(x) / (1 + [g(x)]2)

Product Rule

The product rule is used to differentiate the product of two functions. If f(x) = u(x) * v(x), then f'(x) = u'(x) * v(x) + u(x) * v'(x).

It is particularly useful when dealing with functions that are products of other functions.

Quotient Rule

The quotient rule is used to differentiate the quotient of two functions. If f(x) = u(x) / v(x), then

f'(x) = (u'(x) * v(x) - u(x) * v'(x)) / [v(x)]2.

This rule is essential when dealing with functions that are ratios of other functions.

Implicit and Explicit Equations

Now that we have learned the basic rules of differentiation, we can move on to more advanced topics such as implicit and explicit equations.

Explicit Differentiation: They are normal equations where the dependent variable is explicitly defined in terms of the independent variable and hence their differentiation is straightforward.

Implicit Differentiation: Before we dive into differentiation let us first know what on earth is Implicit Equation.

An Implicit equation is the type of equation in which the dependent variable is not isolated on one side of the equation. The 2 variables in the equation are mixed together such that it is not possible to express one variable explicitly in terms of the other.

For example, the equation x2 + y2 = 1 defines y implicitly as a function of x.

The Core Concept

Differentiate normally with respect to y. Treat y just like you would treat x (for example, the derivative of (y3) with respect to y is (3y2)).

Multiply the result by dy/dx. Because you differentiated a function of y with respect to x, add dy/dx or y' at the end.

Steps to differentiate implicitly:

  1. Take the derivative of both sides with respect to x.
  2. Apply the chain rule where necessary.
  3. Collect all terms involving dy/dx on one side of the equation.
  4. Solve for dy/dx.

Parametric Differentiation

Parametric Equations

Normally, a curve is written as a single equation linking both x and y directly. However, it is sometimes more convenient to define the curve using two separate equations, one for each variable in terms of a third variable called a parameter.

Typically, it looks like this: x = 2t + 7 ; y = 7t + 89. Now you will be asked to find dy/dx

To find dy/dx, we can use the chain rule and differentiate both equations with respect to the parameter t:

dx/dt = 2 ; dy/dt = 7

Now we can find dy/dx by dividing dy/dt by dx/dt:

dy/dx = (dy/dt) / (dx/dt) = 7 / 2

So the derivative of y with respect to x is 7/2.

Applications of Differentiation

Differentiation has numerous applications but in the syllabus we will focus on a few key areas.

Gradients of Curves

The gradient of a curve at a given point is the slope of the tangent line to the curve at that point. It can be found by taking the derivative of the function that defines the curve and evaluating it at the given point.

Equations of Tangent and Normal

The equation of the tangent line to a curve at a given point can be found using the point-slope form of a line, where the slope is the derivative of the function at that point.

The equation of the normal line to a curve at a given point is perpendicular to the tangent line at that point. Its slope is the negative reciprocal of the slope of the tangent line.

m = -1 / (dy/dx of slope)

Once you have the gradient (m) and the point (x1, y1), find the line equation using: y - y1 = m(x - x1).

Increasing and Decreasing Functions

A function is said to be increasing on an interval if its derivative is positive on that interval, and decreasing if its derivative is negative. By analyzing the sign of the derivative, we can determine where a function is increasing or decreasing.

Stationary Points and Their Nature

A stationary point is a point on a curve where the gradient of curve is zero. (dy/dx = 0)

To determine the nature of a stationary point, we can use the second derivative test (derivative of derivative of equation).

  • If the second derivative is positive at the stationary point, it is a local minimum.
  • If the second derivative is negative, it is a local maximum.
  • If the second derivative is zero, the test is inconclusive.

Optimization Problems (Real-World Applications of Maxima and minima)

Optimization problems involves finding the maximum or minimum values of a function subject to certain constraints such as maximizing volume or minimizing cost.

  1. Write an equation for the quantity to be optimized.
  2. Use the constraint to rewrite the equation in terms of a single variable.
  3. Find the critical points by taking the derivative and setting it equal to zero.
  4. Analyze the critical points to determine whether they correspond to maxima or minima.

Connected Rates of Change

When 2 or more variables are changing w.r.t time, we can link rates using the chain rule.

For example, if the radius of a circle is increasing at a rate of 2 cm/s, we can find the rate at which the area is increasing by differentiating the area formula with respect to time.
